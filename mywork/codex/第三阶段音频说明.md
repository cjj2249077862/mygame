# 第三阶段音频：原创合成基础版本

2026-11-26。盘点项目后未发现已有 WAV、OGG、MP3、FLAC 音频或音频来源说明。为完成现有第一章的声音接入，使用本项目新增的 `tools/generate_audio.py` 直接合成 PCM；没有下载音源、引用外部采样、采购素材或借用已知旋律。

这是可替换的基础合成声音与暗氛围音乐，并非录制管弦乐、商业音源包或已经通过听感验收的正式音乐。当前只覆盖菜单、第一章和本章 Boss；第二、三章音乐留到对应内容阶段。

## 接入契约

`scripts/ui/presentation/audio_director.gd` 是纯表现层 `Node`，调用方先加入场景树：

```gdscript
const AudioDirector = preload("res://scripts/ui/presentation/audio_director.gd")
var audio := AudioDirector.new()
add_child(audio)
audio.configure({"master_volume": 0.8, "music_volume": 0.65, "sfx_volume": 0.9})
audio.set_context("menu")
```

- `configure(options: Dictionary)`：`master_volume`、`music_volume`、`sfx_volume` 为 0～1；`audio_enabled` 为总开关。只调整表现，不改变玩法或存档；设置持久化由主界面所属设置模块负责。
- `set_context(context: String)`：`menu`、`chapter`、`boss`；空串／未知上下文淡出音乐。两个音乐播放器在 1.2 秒内交叉渐变，重复设定同一上下文不重播；连续切换保留当前较响的出站层。
- `play_event(event: Dictionary, fast: bool = false)`：读取结算后的事件副本。支持伤害、护盾／格挡、治疗、复活、炸弹、阶段、狂暴、打断、OT、胜负、阵亡和驱散；未知事件忽略，零收益伤害／治疗／护盾不发声。
- 现有核心没有对外追加 `card_play` 或 `cast` 展示记录；界面在核心成功结算后，将 `{"kind": "card_play"}` 放在本次表现队列第一项，首次展示敌方读条时发送 `{"kind": "cast"}`。不能仅因悬停／重绘重复播放。伤害记录的 `hp_loss`／`shield_loss` 只提供既有计算结果，完全由护盾吸收时播放格挡声；混合伤害及旧格式记录兼容原伤害声。
- `stop_all()`：停止音乐和全部 SFX、取消渐变并清空节流状态，供离开场景／测试清理使用。

SFX 同时最多 6 路，每路只播放 1 个声音。普通模式同类音效至少间隔 90ms、普通音效全局至少 55ms；快放分别提升到 240ms／130ms。出牌声保留同类限频，但独立于普通打击的全局间隔，避免快放中出牌声与紧随的命中声互相吞掉。关键警示优先于普通打击，普通声音不能抢掉点名、打断、OT 或胜负短句。胜负短句同类 1.2 秒内不重复。声音不会读取／推进战斗随机数，不反向通知核心结算。
