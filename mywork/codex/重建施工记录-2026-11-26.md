## 配置维护

从 `D:\mygame` 执行：

```powershell
python tools/export_data.py
python tools/export_data.py --check
python tests/test_export_data.py
```

导表工具只依赖 Python 3.11 标准库。第一行是字段名，后续行使用字符串、数值或 Excel 布尔值；不接受公式。所有配置校验成功后整组暂存、备份并替换 JSON，替换异常会回滚。五份 JSON 共用导出批次标识，运行时拒绝混合批次；先完整校验候选配置，失败则保留原先已加载的数据。结构和固定玩法语义由程序维护的 `data/config_contract.json` 统一约束，该文件不作为数值源表。

| 源表 | 工作表与用途 |
| --- | --- |
| `tables/cards.xlsx` | `main`：稳定 ID、文案键、职业或专属施放限制、目标、费用、稀有度、奖励资格、消耗与保留；`effects`：基础／升级、效果顺序、类型、数值、段数、仇恨倍率和卡面占位参数。 |
| `tables/characters.xlsx` | `main`：职业、生命、力量、被动、加成、立绘；`starter`：角色起始牌单与数量。 |
| `tables/encounters.xlsx` | `main`：试炼顺序、敌人组合及金币；`enemies`：敌人属性与打断抗性；`intents`：按顺序循环的行动及附加状态。 |
| `tables/battle_rules.xlsx` | `main`：能量、抽牌、上限、仇恨、战后复活等参数；`statuses`：可驱散性、每层效果及衰减。 |
| `tables/texts_zh_cn.xlsx` | `main`：界面、卡牌、角色、状态、错误提示及事件日志的中文文案。 |

导出的每行含 `_source`，错误可追到源表、工作表、行及字段。卡面使用基础值，悬停预览另计当前角色被动、目标缺血等条件。旧规范的“快速治疗”示例由已确认的【治疗术】承接：其基础治疗初值为 14；改到 18 的验收应先使医者本回合【仁心】已消耗，避免额外加成干扰 18／2 治疗、7／1 仇恨的预期。
